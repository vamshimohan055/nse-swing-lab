Regime filter

Pipeline tags the market on a 60d rolling window:

  • Realized volatility (annualized)
  • Average Directional Index (ADX)
  • Cross-sectional dispersion
  • Index drawdown from rolling peak

How to run

This deployment is a static landing page. The interactive app runs locally:

git clone <repo>
cd nse-swing-lab
pip install -e .
streamlit run src/nse_swing_lab/app.py

Caveats

Mock OHLCV with sector-correlated GBM and regime shifts is used in the absence of Dhan credentials. Survivorship bias applies: today's Nifty 200 is the universe, not point-in-time. Sharpe > 1.5 is the stretch target; 1.0–1.5 is acceptable. Max drawdown target < 20%.
